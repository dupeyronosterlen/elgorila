Códigos QR — Programas de mano digital (El Gorila 2026)

Cada PNG lleva a una versión del programa de mano. Imprimir y colocar donde convenga.

  qr-v1.png  →  Programa v1  
  qr-v2.png  →  Programa v2  
  qr-v3.png  →  Programa v3  
  qr-v4.png  →  Programa v4  

Tamaño: 1000×1000 px. Negro sobre blanco (máximo contraste), URL corta /p1../p4, corrección de errores M; escanean bien en impresión.
URLs: https://elgorilateatro.com.mx/p1 … /p4 (stubs que redirigen a /programa/v1.html … v4.html)

Regenerar: desde la raíz del proyecto, npm run generate-qr
